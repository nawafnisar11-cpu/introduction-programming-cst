## Project: Addition Checker

This small Java program asks the user to:
1. Enter two numbers
2. Calculate their sum mentally
3. Keep trying until the correct answer is entered

### Concepts Used
- Scanner class
- while loop
- conditions
- user input validation

### What I Learned
While building this program, I learned:
- how loops work
- how to repeat input until a condition becomes true
- how Java handles user interaction
  
## How to Run

1. Open the project in Eclipse or any Java IDE
2. Compile the Java file
3. Run the program
4. Enter two numbers and calculate their sum
   
Language:
- Java

